# XBOOK — Student Accounts + Orders + WhatsApp

تم تحديث المشروع مع الحفاظ على هوية XBOOK (الأخضر الداكن + Mint + طابع الملفات السرية).

## الجديد في هذه النسخة

- صفحة حساب طالب مستقلة على `/account`.
- إنشاء حساب طالب: الاسم + الهاتف/واتساب + البريد + كلمة المرور.
- تسجيل دخول وحفظ جلسة الطالب.
- لا يمكن إرسال أي طلب إلا بعد تسجيل الدخول بحساب طالب.
- بيانات الطلب ترتبط بحساب الطالب.
- صفحة حساب الطالب تعرض الطلبات وحالتها.
- عند تغيير حالة الطلب من Control Room، يحاول السيرفر إرسال إشعار تلقائي للطالب على WhatsApp عبر Meta WhatsApp Cloud API.
- دعم أرقام مصر التي تبدأ بـ `01` وتحويلها تلقائياً إلى صيغة دولية.
- رسائل وحالات الطلب بالعربي.
- تكبير بسيط لأحجام الخطوط وتحسين القراءة.
- Animations وHover وTransitions وModal animations وWhatsApp pulse مع احترام `prefers-reduced-motion`.
- الحفاظ على Dark Mode والهوية البصرية الحالية.
- Control Room الحالية تعمل كما هي.

## تشغيل المشروع

```bash
npm install
npm start
```

ثم:
- الموقع: `/`
- حساب الطالب: `/account`
- الإدارة: `/admin`

## PostgreSQL

ضع `DATABASE_URL` في متغيرات البيئة. عند تشغيل المشروع لأول مرة سيتم إنشاء الجداول تلقائياً، والنسخة الجديدة تضيف جدول `students` وتضيف `student_id` لجدول الطلبات بدون حذف البيانات القديمة.

## WhatsApp التلقائي

لإرسال إشعار فعلي عند تغيير حالة الطلب، استخدم Meta WhatsApp Cloud API وضع:

- `WHATSAPP_TOKEN`
- `WHATSAPP_PHONE_NUMBER_ID`
- `WHATSAPP_API_VERSION` (مثلاً `v23.0`)

يمكنك ترك `WHATSAPP_TEMPLATE_NAME` فارغاً لاستخدام رسالة نصية، لكن رسائل WhatsApp التي يبدأها النشاط التجاري خارج نافذة خدمة العميل قد تتطلب **قالب WhatsApp معتمداً** من Meta.

إذا استخدمت Template، اجعله يحتوي على متغيرين في Body بالترتيب:
1. رقم الطلب
2. حالة الطلب

ثم ضع:
- `WHATSAPP_TEMPLATE_NAME`
- `WHATSAPP_TEMPLATE_LANG`

بعدها أي تغيير من:
`جديد → قيد التجهيز → تم الشحن → مكتمل / ملغي`
سيحاول السيرفر إرسال الإشعار تلقائياً.

> مهم: لا تضع Token داخل ملفات JavaScript في `public`. يجب أن يبقى داخل متغيرات البيئة على Render/Railway.

## Render

1. اربط المستودع من GitHub.
2. تأكد أن Build Command هو `npm install`.
3. Start Command هو `npm start`.
4. أضف `DATABASE_URL` و`JWT_SECRET` وبيانات الإدارة.
5. أضف متغيرات WhatsApp إذا أردت الإشعارات التلقائية.
6. بعد النشر افتح `/account` لتجربة إنشاء حساب طالب، ثم أنشئ طلباً وغيّر حالته من `/admin`.

## ملاحظات

- لا يوجد دفع إلكتروني في المشروع.
- تصفح الكتب لا يحتاج حساباً؛ **إرسال الطلب فقط يحتاج حساب طالب**.
- لا تحفظ كلمات المرور كنص عادي؛ يتم تخزينها باستخدام bcrypt.
